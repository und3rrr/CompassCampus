## 🎓 ФУНКЦИОНАЛ КОРИДОРА

### Как это работает

```python
# Режим коридора в on_touch_down:

elif self.editor_mode == 'corridor':
    if clicked_node.node_type == 'Corridor':
        # Click на коридор = выбираем его
        self.corridor_nodes = [clicked_node]
    else:
        # Click на кабинет = соединяем с коридором
        edge = (clicked_node.id, corridor_node.id)
        self.edges.append(edge)
```

### Пример использования

```
1. Создать точку "Коридор" (Тип: Corridor)
2. Создать "Каб1", "Каб2", "Каб3" (Тип: Room)
3. ➕ КОРИДОР режим включили
4. Click Коридор → выбран
5. Click Каб1 → связано
6. Click Каб2 → связано
7. Click Каб3 → связано

Результат: 3 ребра вместо 3×2/2 = 3 ребра
(В данном случае одинаково, но для 100 кабинетов:
 Было: 100×99/2 = 4950 рёбер
 Стало: 100 рёбер
 Экономия: 4850 рёбер!)
```
