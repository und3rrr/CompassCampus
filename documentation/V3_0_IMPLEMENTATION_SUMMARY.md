### ✅ 1. Номера кабинетов над невидимым графом

```
ТРЕБОВАНИЕ: 
"реализовать постановку номера кабинета над невидимым графом, 
чтобы при близком зуме и дальнем зуме он показывался корректно"

✅ РЕАЛИЗОВАНО:
- Файл: widgets/map_widget.py (строки 1020-1055)
- Текстовые метки над каждым узлом
- Размер текста зависит от уровня зума: font_size = max(8, int(14 * zoom))
- Видимость: включается при zoom >= 0.5x
- Адаптивный: масштабируется плавно вместе с картой
- Совместимость: работает со всеми типами узлов
```

**Код**:
```python
if self.zoom >= 0.5:
    font_size = max(8, int(14 * self.zoom))
    for node in self.nodes:
        display_text = node.name if node.node_type != 'Corridor' else '🚶'
        label = CoreLabel(text=display_text[:15], font_size=f'{font_size}sp')
        label.refresh()
        # Отрисовка текстуры с белым фоном
```
