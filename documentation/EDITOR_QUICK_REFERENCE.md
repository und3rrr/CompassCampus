# 🎯 КРАТКАЯ СПРАВКА РЕДАКТОРА v2.0

## 📍 4 РЕЖИМА В ОДНОЙ СТРОКЕ

| 🎨 Режим | ⚡ Кнопка | 📝 Действие | ⌨️ Как |
|---------|----------|-----------|-------|
| ☝️ Выбор | Green | Выбрать, переместить | Click / Shift+Click / Drag |
| 🔗 Связь | Blue | Соединить 2 точки | Click 1-я → Click 2-я |
| ✕ Удал | Red | Удалить точку | Click на точку |
| ➕ Кор | Yellow | Коридор-коннектор | Click корридор → Click кабинеты |

---

## 🚀 БЫСТРЫЙ СТАРТ

```
1. ℹ️ ОТКРЫТЬ СПРАВКУ
2. ➕ ДОБАВИТЬ «Коридор» (Тип: Corridor)
3. ➕ ДОБАВИТЬ кабинеты (Тип: Room)
4. ➕ КОРИДОР режим → соединяй кабинеты
5. 💾 СОХРАНИ
```

---

## 📊 СРАВНЕНИЕ РЕЖИМОВ

### ☝️ ВЫБОР

```
✅ Для: Перемещение точек, многовыбор
✓ Click          = выбрать 1
✓ Shift+Click    = добавить в выделение
✓ Drag           = переместить
```

### 🔗 СВЯЗЬ

```
✅ Для: Создание рёбер между точками
✓ Click на А     = выбрать начало
✓ Click на Б     = создать A→B
```

### ✕ УДАЛЕНИЕ

```
✅ Для: Удалить точку с её рёбрами
✓ Click на точку = удалить
```

### ➕ КОРИДОР

```
✅ Для: Создать централизованную связь
✓ Click корридор = выбрать коридор
✓ Click кабинет  = соединить (1 click = 1 связь)
```

## ⌨️ ГОРЯЧИЕ КЛАВИШИ

```
Scroll Up    = Приблизить (зум +)
Scroll Down  = Отдалить (зум -)
Shift+Click  = Мультивыбор
Drag         = Переместить

↶  (Btn) = Отмена
↷  (Btn) = Возврат
💾 (Btn) = Сохранить
```

---

## 🐛 ЧТО ДЕЛАТЬ ЕСЛ...

| ❓ Проблема | ✅ Решение |
|----------|----------|
| Точки не видны | Scroll Down (отдалить) |
| Не могу выбрать | ☝️ режим + Click |
| Не создаётся ребро | 🔗 режим + Click А + Click Б |
| Прокли удалили | ↶ нажми Отмена |
| Коридор не работает | Используй тип "Corridor" |
| Фон не загрузился | Проверь папку plans/ |

## 💡 ХИТРОСТИ

```
🔑 Коридоры экономят тысячи рёбер!

ДО:  Каждый к каждому (N×M рёбер)
     Комната1─┬─Комната2
               │
             Комната3

ПОСЛЕ: Через коридор (N рёбер)
     Комната1─┐
     Комната2─┼─Коридор
     Комната3─┘
```
