### 1️⃣ Номера кабинетов над графом с масштабированием

**Файл**: [widgets/map_widget.py](widgets/map_widget.py)

**Реализация**:
- ✅ Отрисовка текстовых меток над узлами
- ✅ Автоматическое масштабирование при зуме (от 0.5x до ∞)
- ✅ Размер шрифта зависит от уровня зума
- ✅ Белый фон под текстом для читаемости
- ✅ Максимум 15 символов на метку
- ✅ Поддержка всех типов узлов (Room, Corridor, Staircase, Elevator)

```python
# ДО (без меток):
# Узлы отображаются как цветные точки

# ПОСЛЕ (с метками):
📍 Кабинет 101
🚶 Коридор
🔴 Лифт
```

**Поведение**:
- При зуме < 0.5x - метки скрыты (для чистоты интерфейса)
- При зуме >= 0.5x - метки появляются
- Размер текста: `14 * zoom` (пиксели)
- Позиция: над каждым узлом, центрирована

### 3️⃣ Переработанный интерфейс - Modern Bottom Sheet

**Файл**: [widgets/modern_bottom_sheet.py](widgets/modern_bottom_sheet.py) (НОВЫЙ)

#### 📱 Новая архитектура

| Элемент | Поведение |
|---------|-----------|
| **Bottom Sheet** | Занимает 35% экрана (треть) |
| **Анимация** | Появляется снизу за 0.3 сек |
| **Позиция** | Внизу экрана, над диспетчером элементов |
| **Карта** | **Остаётся полностью кликабельной** |
| **Закрытие** | Клик на оверлей или кнопка |

#### 🎨 Дизайн

```
╔═══════════════════════════════════╗
║     📌 КАБИНЕТ 101                 ║  ← Название узла (20sp, bold)
├─────────────────────────────────┤
║ 📍 Тип: Room                      ║  ← Информация узла
║ 🏢 Этаж: 1                        ║
├─────────────────────────────────┤
║  📍 ОТСЮДА  │  🎯 СЮДА           ║  ← Большие кнопки, современный стиль
╚═══════════════════════════════════╝
```

#### 🔑 Ключевые компоненты

```python
class ModernBottomSheet(FloatLayout):
    """
```

### 4️⃣ Новая терминология: ОТСЮДА / СЮДА

**Замена**: ❌ "Старт" / "Конец" → ✅ "ОТСЮДА" / "СЮДА"

**Где меняется:**
- Bottom Sheet кнопки: 
  - `📍 ОТСЮДА` (зелёная, левая)
  - `🎯 СЮДА` (синяя, правая)
- Методы:
  - `_set_start_node()` → `_set_from_node()`
  - `_set_end_node()` → `_set_to_node()`
  - (старые методы оставлены для совместимости)

**Иконки**:
- ОТСЮДА: `📍` (красное булавка)
- СЮДА: `🎯` (мишень)

### Отрисовка номеров - Масштабирование

```python
# Формула размера шрифта
font_size = max(8, int(14 * self.zoom))

# Примеры:
zoom=0.5  → font_size=7  (округляется до 8)
zoom=1.0  → font_size=14
zoom=2.0  → font_size=28
zoom=4.0  → font_size=56
```

**Видимость текста**:
- При zoom < 0.5x → текст скрыт
- При zoom >= 0.5x → текст видимый
- Плавно масштабируется вместе с картой
