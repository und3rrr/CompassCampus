# 🎬 БЫСТРЫЙ СТАРТ: КОРИДОРЫ И ЗУМ

**Готово к использованию сразу!**

---

## ⚡ НОВОЕ В РЕДАКТОРЕ

### 1. Создание коридора за 1 клик

**Представь**: Я хочу создать пересадочный узел в центре этажа

**ДО**:
```
1. Нажать "+ Точка"
2. Ввести имя
3. Выбрать тип "Corridor"
4. Click OK
```

**ТЕПЕРЬ** (быстрее):
```
1. Кнопка ➕ КОРИДОР
2. ДВОЙНОЙ КЛИК в нужное место
3. ГОТОВО! 🎉
```

### 2. Легко увеличивать/уменьшать план

**Кнопки зумирования** прямо в верхней панели:

```
┌─────────────────────────────────────────┐
│ ... Этаж ... 🔍− | 130% | 🔍+ | ⟲ 1x ... │  <- НОВЫЕ КНОПКИ!
└─────────────────────────────────────────┘
```

- **🔍−** = Отдалить (сделать план меньше)
- **Процент** = Текущий уровень (100%, 110%, и т.д.)
- **🔍+** = Приблизить (сделать план больше)
- **⟲ 1x** = Сброс на 100% и центрирование

## 🎯 ПРИМЕР: СОЗДАНИЕ ПЛАНА С КОРИДОРАМИ

### Шаг 1: Откройте редактор

```
1. Home → Выбери здание → Перейти на редактор
2. Выбери этаж (1-5)
3. Откроется план этажа
```

### Шаг 2: Создай коридор (быстро!)

```
1. Нажми кнопку ➕ КОРИДОР (она жёлтая)
2. Она выделится белым цветом = активна
3. ДВОЙНОЙ КЛИК в ЦЕНТР этажа
   - На сенсорном: быстро два раза в одно место
   - На компьютере: быстро два раза кликни мышкой
4. Готово! Коридор создан! 🎉
```

### Шаг 3: Соедини кабинеты с коридором

```
1. Нажми кнопку 🔗 СВЯЗАТЬ (она синяя)
2. Click на коридор
3. Click на кабинет
4. They are connected! ✓
5. Повтори для всех кабинетов
```

### Шаг 4: Если план большой - используй зум!

```
Если план не помещается на экран:

1. Нажми 🔍− чтобы отдалить
2. Или нажми ⟲ 1x чтобы сбросить и центрировать
3. Когда увидишь нужное место - нажми 🔍+
```

### Шаг 5: Сохрани!

```
1. Нажми 💾 СОХР вверху
2. Plan сохранится на сервер
3. Готово! ✓
```

## 💡 СОВЕТЫ ПРО

### Совет 1: Быстрое создание нескольких коридоров

```
1. ➕ КОРИДОР режим
2. Двойной клик → коридор 1 ✓
3. Двойной клик → коридор 2 ✓
4. Двойной клик → коридор 3 ✓
Режим не переключается - создавай сколько надо!
```

### Совет 2: Правильный зум для работы

```
Когда план очень большой:
1. 🔍− несколько раз (50-60%)
2. Видишь весь этаж
3. Найди нужное место
4. Нажми ⟲ 1x
5. Система центрирует на то место
6. Готово к редактированию!
```

### Совет 3: Undo/Redo работают отлично

```
Ошибся? Не проблема!
1. Нажми ↶ (Undo) = отменить
2. Нажми ↷ (Redo) = вернуть

Это касается и коридоров и всего остального!
```

## 🚫 ОШИБКИ И РЕШЕНИЯ

### "Двойной клик не создаёт коридор"

```
✅ Проверь:
1. Выбран режим ➕ КОРИДОР? (должна быть белая)
2. Двойной клик?
   - Не одиночный клик!
   - Два клика быстро в одно место
   - На сенсор: два тапа
```

### "Не могу найти нужное место на плане"

```
✅ Используй зумирование:
1. 🔍− чтобы отдалить и видеть весь план
2. Найди нужное место
3. 🔍+ чтобы приблизить и работать
4. Или нажми ⟲ 1x для сброса
```

### "Случайно создал в не том месте"

```
✅ Не проблема:
1. Нажми ↶ (Undo)
2. Создай заново!
```

## 🔑 КЛЮЧЕВЫЕ КНОПКИ

| Где | Кнопка | Назначение |
|-----|--------|-----------|
| **Верхняя строка** | 🔍− | Отдалить план |
| **Верхняя строка** | 100% | Текущий процент зума |
| **Верхняя строка** | 🔍+ | Приблизить план |
| **Верхняя строка** | ⟲ 1x | Сброс на 100% |
| **Вторая строка** | ➕ КОРИДОР | Режим создания коридоров |
| **Помощь** | ℹ️ | Полная инструкция |

## 📱 ЕСЛИ НА МОБИЛЬНИКЕ

### Двойной клик

```
Палец на экран - быстро 2 раза в одно место:
TAP → TAP (очень быстро!)

Или можно медленнее если система не создаёт коридор:
TAP (отпусти) → быстро TAP (снова) 
```

### Зумирование

```
Кнопки зумирования:
- 🔍− = нажми 1-2 раза чтобы отдалить
- 🔍+ = нажми 1-2 раза чтобы приблизить
- ⟲ 1x = сброс

Или колёсико (если есть):
- Два пальца вверх = приблизить
- Два пальца вниз = отдалить
```
