## 🎬 ПРОЦЕСС СОЗДАНИЯ КОРИДОРА

### ЭТО БЫЛ ПРОЦЕСС (v2.0):

```
1. Нажми + Точка → Диалог
   ├─ Введи имя: "Коридор 1"
   ├─ Выбери тип: Room → Corridor
   └─ Нажми OK
   
2. Выбери место на плане
   
3. Коридор создан
```

### ТЕПЕРЬ ПРОЦЕСС (v2.1):

```
1. Нажми ➕ КОРИДОР
   └─ Кнопка белеет (активна)

2. ДВОЙНОЙ КЛИК на план
   └─ Готово! 🎉
   
3. Коридор создан в 1 действие!
```

## 🔍 КНОПКИ ЗУМИРОВАНИЯ - ПОДРОБНО

### Кнопка: 🔍−  "Отдалить"

```
ДО:  Плану слишком тесно на экране

↓ Click 🔍−

ПОСЛЕ: Виден весь план
```

**Диапазон**: До 0.2x (очень отдалено)

### Кнопка: 100% "Процент зума"

```
Показывает текущий уровень:
  
  100%  = норма (1.0x, как в реальности)
  50%   = отдалено (0.5x, видишь половину размера)
  200%  = приближено (2.0x, видишь в 2 раза больше)
  
Обновляется в реальном времени
```

### Кнопка: 🔍+ "Приблизить"

```
ДО:  Не видишь детали, нужно ближе

↓ Click 🔍+

ПОСЛЕ: Видны детали, удобнее редактировать
```

**Диапазон**: До 5.0x (максимум приближено)

### Кнопка: ⟲1x "Сброс"

```
ПО НАЖАТИЮ:
  ✓ Зум = 100% (нормальный размер)
  ✓ Pan = 0, 0 (центрирование)
  ✓ План в центре экрана
  
Быстро вернуться к "нормальному виду"
```

## 🎮 СЦЕНАРИИ ИСПОЛЬЗОВАНИЯ

### Сценарий 1: Большой этаж, нужно работать в центре

```
Этаж 1: Очень большой план (100+ комнат)

ШАГ 1: 🔍− (отдаление)
  → план целиком на экране (50%)
  
ШАГ 2: Найди нужный коридор в центре
  
ШАГ 3: ⟲1x (сброс)
  → центрируется на карте
  
ШАГ 4: 🔍+ (приближение)
  → видишь детали нужного коридора
  
ШАГ 5: Редактируй! ✓
```

### Сценарий 2: Создание коридоров на плане

```
ШАГ 1: Нажми ➕ КОРИДОР (жёлтая кнопка)
  
ШАГ 2: ДВОЙНОЙ КЛИК в центр этажа
  → Коридор 1 создан ✓
  
ШАГ 3: ДВОЙНОЙ КЛИК в другое место
  → Коридор 2 создан ✓
  
ШАГ 4: ДВОЙНОЙ КЛИК ещё раз
  → Коридор 3 создан ✓
  
ШАГ 5: Режим коридора ещё активен!
  → Можешь создавать дальше или нажать другой режим
```

### Сценарий 3: Детальная работа с планом

```
ШАГ 1: 🔍+ (приблизить)
  → 150% - видишь детали
  
ШАГ 2: 🔍+ ещё раз
  → 200% - видишь очень хорошо
  
ШАГ 3: Редактируй с точностью
  
ШАГ 4: Ошибка? ↶ Undo
  
ШАГ 5: 🔍− (отдалить)
  → 100% - нормальный вид
  
ШАГ 6: Сохрани! 💾
```

## ⌨️ ГОРЯЧИЕ КОМБИНАЦИИ (что работает)

### Создание коридора

```
Режим ➕ КОРИДОР + ДВОЙНОЙ КЛИК = Новый коридор
```

### Зумирование

```
🔍+ кнопка      = Приблизить (10% шаг)
🔍− кнопка      = Отдалить (10% шаг)
⟲1x кнопка      = Сброс на 100%
Колёсико вверх  = Приблизить (ещё работает!)
Колёсико вниз   = Отдалить (ещё работает!)
```

### Общее

```
↶ кнопка        = Undo (отмена)
↷ кнопка        = Redo (возврат)
💾 кнопка       = Сохранить
```

## 🚨 ТИПИЧНЫЕ ОШИБКИ И РЕШЕНИЯ

| Ошибка | Решение |
|--------|---------|
| Двойной клик не работает | Убедись что режим ➕ КОРИДОР активен (белый) |
| Не вижу весь план | Нажми 🔍− несколько раз или ⟲1x |
| Не вижу детали | Нажми 🔍+ или ⟲1x и потом 🔍+ |
| Случайно создал коридор | Нажми ↶ Undo, попробуй заново |
| План "потеялся" за краем | Нажми ⟲1x = центрирует на карту |
