## 🔍 АНАЛИЗ

### Что происходило (ДО):

1. **Редактор**: Точки связаны (рёбра видны, правильные)
2. **При поиске маршрута**: 
   - API не отвечает → fallback на локальный граф
   - **Локальный граф перестраивается автоматически**
   - Использует `GraphBuilder.build_edges_from_nodes()`
   - Это функция ищет рёбра на основе **БЛИЗОСТИ** (150 пиксели)
   - Когда вы двигаете узлы на изображение, расстояния меняются!
   - Рёбра больше не проходят через фильтр близости
   - **Граф теряет все рёбра!**

### Почему происходит:

```python
# ПЛОХО (ДО):
def _calculate_route_locally(self):
    # Автоматически создаёт рёбра по близости
    edges = GraphBuilder.build_edges_from_nodes(nodes_dicts)
    # build_edges_from_nodes ищет рёбра на расстояние <= 150px
    # Но в редакторе вы сохранили другие рёбра!
```

## ✅ РЕШЕНИЕ

### Что изменилось:

```python
# ХОРОШО (ПОСЛЕ):
def _calculate_route_locally(self):
    if self.building.edges:
        # Пользуемся СОХРАНЁННЫМИ рёбрами из редактора!
        edge_objects = []
        for from_id, to_id in self.building.edges:
            from_node = nodes_map.get(str(from_id))
            to_node = nodes_map.get(str(to_id))
            
            if from_node and to_node:
                distance = GraphBuilder.calculate_distance(...)
                edge_objects.append(GraphEdge(...))
        
        edges = edge_objects
        logger.info(f"✓ Using {len(edges)} edges from building graph")
    else:
        # Только если нет сохранённых рёбер
        edges = GraphBuilder.build_edges_from_nodes(nodes_dicts)
```

### Что это значит:

```
РАНЬШЕ:
  Граф переди = Автоматическое поколение на основе расстояния
  
ТЕПЕРЬ:
  Граф переди = Используются СОХРАНЁННЫЕ рёбра из редактора
  Fallback = Автоматическое поколение (если нет сохранённых)
```

# Строка ~1009: Улучшена функция _on_node_moved
def _on_node_moved(self, node):
    # Обновляем координаты в здании при движении узла
    if self.building:
        building_node = next((n for n in self.building.nodes if n.id == node.id), None)
        if building_node:
            building_node.x = node.x
            building_node.y = node.y
    
    self._save_state()
