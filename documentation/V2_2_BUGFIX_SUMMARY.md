## 🔍 КОРНЕВАЯ ПРИЧИНА

**Проблема**: Локальный поиск маршрута **переперестраивал граф** на основе **близости узлов**.

```python
# ДО (ПЛОХО):
edges = GraphBuilder.build_edges_from_nodes(nodes_dicts)
# Ищет рёбра только если расстояние <= 150px
# Но в редакторе узлы двигались - расстояния менялись!
# Результат: граф без рёбер
```

**Решение**: Использовать **сохранённые рёбра из редактора** вместо автогенерирования.

```python
# ПОСЛЕ (ХОРОШО):
if self.building.edges:
    # Используем рёбра, которые создали в редакторе!
    for from_id, to_id in self.building.edges:
        # создаём GraphEdge объект...
    edges = edge_objects
```

def _on_node_moved(self, node):
    """Callback при движении узла"""
    # Обновляем координаты в здании
    if self.building:
        building_node = next((n for n in self.building.nodes if n.id == node.id), None)
        if building_node:
            building_node.x = node.x
            building_node.y = node.y

## 💡 ДОПОЛНИТЕЛЬНАЯ ИНФОРМАЦИЯ

### Почему это случилось

Система имела двойную логику:
- Локальный поиск (GraphBuilder) создавал рёбра **на лету**
- Редактор сохранял рёбра **в памяти**

Они не были синхронизированы! Когда координаты менялись, локальная логика не знала о сохранённых рёбрах и пересчитывала всё заново - неправильно.

### Как это работает теперь

Система имеет единую логику:
- Редактор: сохраняет рёбра
- Поиск маршрута: использует сохранённые рёбра
- Fallback: создаёт рёбра только если они не сохранены

Всё синхронизировано!
