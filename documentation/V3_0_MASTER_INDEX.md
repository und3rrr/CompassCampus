### 📍 Feature 1: Номера кабинетов

```python
# Как это работает:
1. При зуме < 0.5x → номера скрыты ❌
2. При зуме >= 0.5x → номера видны ✅
3. Размер шрифта = 14 * zoom (плавное масштабирование)
4. При зуме 1.0x → размер 14sp
5. При зуме 2.0x → размер 28sp

# Файл: widgets/map_widget.py (строки 1020-1055)
```

### 🏠 Feature 2: Последний корпус

```python
# Как это работает:
1. При выборе корпуса → cache.set('last_building_id', id) ✅
2. При запуске → cache.get('last_building_id') ✅
3. Если найдено → загружаем автоматически ✅
4. Если не найдено → fallback на первый корпус ✅
```

## 🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проблема 1: Номера не появляются

```
Решение:
1. Проверь zoom: должен быть >= 0.5
2. В логах найди: "zoom=X.XX"
3. Убедись что это >= 0.5
4. Нажми "🔍+" чтобы увеличить
```

### Проблема 2: Последний корпус не загружается

```
Решение:
1. Убедись что cache работает
2. При выборе корпуса должно быть:
   "Saved last building ID: 42"
3. При загрузке должно быть:
   "Loaded last building: 42"
4. Если не видать - очисти кэш
```

### Проблема 3: Bottom Sheet не открывается

```
Решение:
1. Убедись что импорт есть:
   from widgets.modern_bottom_sheet import ModernBottomSheet
2. При клике на узел должно быть:
   logger.info обновление
3. Проверь что на_node_selected_callback установлен
```
