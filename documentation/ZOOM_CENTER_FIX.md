# Центрированный зум - FIXED ✅

**Дата**: 26 февраля 2026  
**Проблема**: Зум приближал/отдалял вбок вместо центра экрана  
**Статус**: Решено ✅

## 🎯 Проблема

При использовании колесика мыши для зума карта смещалась в сторону вместо масштабирования относительно центра экрана.

**Было:**
```
Пользователь крутит колесико мыши
  ↓
Zoom изменяется
  ↓
Карта смещается в сторону ❌
```

**Стало:**
```
Пользователь крутит колесико мыши
  ↓
Zoom изменяется ОТНОСИТЕЛЬНо центра экрана
  ↓
Карта остаётся на месте ✅
```

## ✅ Решение

### Принцип

При зуме нужно:
1. Найти, что находится в центре экрана (в мировых координатах)
2. Изменить zoom
3. Пересчитать pan так, чтобы тот же объект остался в центре

### Формула

```python
# 1. Центр экрана (в экранных координатах)
center_screen_x = self.width / 2
center_screen_y = self.height / 2

# 2. Что в центре (в мировых координатах)
center_world_x, center_world_y = self._screen_to_world(center_screen_x, center_screen_y)

# 3. Изменяем zoom
self.zoom *= 1.1  # приближение

# 4. Пересчитываем pan для сохранения центра
self.pan_x = center_screen_x - center_world_x * self.zoom
self.pan_y = center_screen_y - center_world_y * self.zoom
```

## 🔧 Что было изменено

### 1. `widgets/visual_graph_editor.py`

**Методы обновлены:**
- `on_scroll_down()` - зум вверх (приближение)
- `on_scroll_up()` - зум вниз (отдаление)

**Логика:**
```python
def on_scroll_down(self, *args):
    # Сохраняем центр
    center_screen_x = self.width / 2
    center_screen_y = self.height / 2
    center_world_x, center_world_y = self._screen_to_world(center_screen_x, center_screen_y)
    
    # Приближаем
    self.zoom *= 1.1
    
    # Пересчитываем pan
    self.pan_x = center_screen_x - center_world_x * self.zoom
    self.pan_y = center_screen_y - center_world_y * self.zoom
    
    self._update_canvas()
```

## 🔍 Технические детали

### Координатная система

```
Экранные координаты (screen)
  ↓ _screen_to_world()
Мировые координаты (world)
  ↓ zoom/pan
Обратно в экранные
```

### Преобразования

**screen_to_world:**
```python
world_x = (screen_x - pan_x) / zoom
world_y = (screen_y - pan_y) / zoom
```

**world_to_screen:**
```python
screen_x = world_x * zoom + pan_x
screen_y = world_y * zoom + pan_y
```
