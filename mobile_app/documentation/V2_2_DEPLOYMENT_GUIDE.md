## 🆘 ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### Проблема: "Маршрут не найден" (ещё)

**Решение**:
```
1. Проверить логи:
   - [INFO] ✓ Using X edges... → OK
   - [WARNING] No edges... → рёбра не сохранены

2. Если рёбра не сохранены:
   - Перейти в редактор
   - Проверить что рёбра есть
   - Нажать 💾 СОХР
   - Повторить поиск

3. Если логи не показываются:
   - Проверить что уровень логирования = INFO или DEBUG
   - Проверить что приложение перезагружено правильно
```

### Проблема: Синтаксис ошибка

**Решение**:
```
1. Проверить файлы целостны:
   python -m py_compile screens/map_screen.py

2. Если ошибка → восстановить из backup:
   cp screens/map_screen.py.backup screens/map_screen.py

3. Проверить что git pull принёс все изменения:
   git status
   git diff screens/map_screen.py
```

### Проблема: Старые рёбра не используются

**Решение**:
```
1. Очистить кэш:
   rm -rf ~/.cache/*  (если есть кэш локальный)

2. Перезагрузить приложение полностью

3. Проверить логи:
   [INFO] Building graph state: X nodes, Y edges
```
