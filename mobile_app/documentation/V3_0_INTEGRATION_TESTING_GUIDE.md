## 🧪 ТЕСТИРОВАНИЕ

### Модульное тестирование

#### 1️⃣ Тест загрузки последнего корпуса

**Действие**:
```
1. Запустить приложение
2. Перейти на экран карты
3. Если первый запуск - откроется первый корпус ✅
4. Выбрать другой корпус через меню
5. Закрыть приложение полностью
6. Запустить заново
7. ✅ Должен открыться выбранный корпус
```

**Вывод в логах**:
```
INFO: Saved last building ID: 42
...
INFO: Loaded last building: 42
```

---

#### 2️⃣ Тест Modern Bottom Sheet

**Действие**:
```
1. На экране карты нажать на жюбой узел
2. ✅ Sheet появляется снизу (25-35% экрана)
3. ✅ Видно название узла, тип, этаж
4. ✅ Две кнопки: "📍 ОТСЮДА" (зелёная) и "🎯 СЮДА" (синяя)
5. Нажать "ОТСЮДА"
6. ✅ Sheet закрывается, узел становится стартовой точкой
7. Нажать на другой узел
8. ✅ Sheet появляется заново
9. Нажать "СЮДА"
10. ✅ Sheet закрывается, строится маршрут
```

**Вывод в логах**:
```
INFO: Start node set (ОТСЮДА): Кабинет 101
INFO: End node set (СЮДА): Кабинет 205
INFO: ✓ Маршрут (API): Кабинет 101 → Кабинет 205 | Расстояние: 45м | Время: 32мин
```

---

#### 3️⃣ Тест отрисовки номеров кабинетов

**Действие**:
```
1. На экране карты при зуме 0.3x:
   ✅ Номера кабинетов НЕ видны

2. Нажать кнопку "🔍+" (zoom in) несколько раз:
   ✅ При зуме около 0.5x - появляются первые номера
   
3. Продолжить масштабирование:
   ✅ Номера становятся всё больше и читаемее
   
4. Нажать "↺" (reset):
   ✅ Номера снова исчезают при мальком зуме

5. Скачать/перемещать карту (pan):
   ✅ Номера остаются на месте над узлами
```

**Вывод в логах**:
```
zoom=0.3 → номера скрыты
zoom=0.7 → font_size=10px, видны
zoom=1.5 → font_size=21px, хорошо видны
zoom=3.0 → font_size=42px, очень крупно
```

```
3. Проверить интерактивность:
   ✅ Все кнопки кликабельны
   ✅ Карта кликабельна (узлы выбираются)
```

## 🐛 ОТЛАДКА

### Проблема: Номера не видны при зуме >= 0.5x

**Решение**:
```python
# Проверить в map_widget.py строку:
if self.zoom >= 0.5:  # ← Должно быть >= чтобы включить отрисовку
    # отрисовка текста
    
# Если не работает:
1. Проверить что zoom вычисляется правильно
2. В логах посмотреть: "zoom=X.XX"
3. Убедиться что это >= 0.5
```

### Проблема: Bottom Sheet не открывается

**Решение**:
```python
# Проверить что ModernBottomSheet импортирован:
from widgets.modern_bottom_sheet import ModernBottomSheet  ✅

# Проверить что callback установлен:
self.map_widget.on_node_selected_callback = self.on_map_node_selected  ✅

# В логах должно быть:
DEBUG: Node clicked: Кабинет 101
```

### Проблема: Последний корпус не загружается

**Решение**:
```python
# Проверить что кэш работает:
cache_service.get('last_building_id')  # Должна вернуть ID

# Проверить логи:
INFO: Saved last building ID: 42
...
INFO: Loaded last building: 42  ✅

# Если не срабатывает:
1. Очистить кэш вручную:
```
