### 4️⃣ **Функционал КОРИДОРА (новое!)**

**Проблема**: Нужно соединить 100 кабинетов = 10,000 рёбер

**Решение**: 
1. Создать точку типа "Corridor"
2. Включить режим "➕ Коридор"
3. Click на коридор
4. Click на каждый кабинет
5. **Результат**: Только 100 рёбер! (в 100 раз меньше)

```python
elif self.editor_mode == 'corridor':
    if clicked_node.node_type == 'Corridor':
        self.corridor_nodes = [clicked_node]  # Выбраны коридор
    else:
        # Соединяем кабинет с коридором
        edge = (clicked_node.id, corridor_node.id)
        self.edges.append(edge)
```
