# Canvas Clipping Quick Reference

## Проблема и решение

**Проблема**: Элементы карты выходят за границы виджета и перекрывают UI  
**Решение**: Добавлена обрезка содержимого Canvas с `ScissorPush`/`ScissorPop`

## Изменённые файлы
