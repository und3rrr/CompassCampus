**Новые методы обработки** (+40 строк):

```python
def _zoom_in(self, instance):
    """Обработка нажатия 🔍+"""
    self.graph_editor.zoom_in()
    self.zoom_label.text = f'{int(self.graph_editor.zoom * 100)}%'
    self.info_label.text = f'🔍 Приближение: {int(self.graph_editor.zoom * 100)}%'

def _zoom_out(self, instance):
    """Обработка нажатия 🔍−"""
    self.graph_editor.zoom_out()
    self.zoom_label.text = f'{int(self.graph_editor.zoom * 100)}%'
    self.info_label.text = f'🔍 Отдаление: {int(self.graph_editor.zoom * 100)}%'

def _zoom_reset(self, instance):
    """Обработка нажатия ⟲ 1x"""
    self.graph_editor.reset_zoom()
    self.zoom_label.text = '100%'
    self.info_label.text = '🔍 Зум сброшен на 100%'
```
