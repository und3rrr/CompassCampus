## 🎯 НОВЫЕ РЕЖИМЫ РЕДАКТИРОВАНИЯ

### 1. ☝️ РЕЖИМ ВЫБОРА (Select)
- ✓ Click = выбрать одну точку
- ✓ Shift+Click = добавить в выделение
- ✓ Drag = переместить выбранную(ые) точку(и)
- **Идеален для**: позиционирования точек на плане

### 2. 🔗 РЕЖИМ СВЯЗИ (Link)
- ✓ Click первую точку
- ✓ Click вторую точку → создано ребро
- ✓ Не создаёт дубли рёбер
- **Идеален для**: создания соединений между точками

### 3. ✕ РЕЖИМ УДАЛЕНИЯ (Delete)
- ✓ Click на точку → удаляется с её рёбрами
- ✓ Без подтверждения (быстрое удаление)
- **Идеален для**: удаления ошибочных точек

### 4. ➕ РЕЖИМ КОРИДОРА (Corridor) 🆕
- ✓ Click на точку типа "Corridor" → выбираем коридор
- ✓ Click на кабинет → соединяем с коридором
- ✓ Каждый клик = одна связь
- **Идеален для**: создания пересадочных узлов

```
ПРОБЛЕМА: Было N×M рёбер между всеми кабинетами
РЕШЕНИЕ:  Коридор экономит до 99% рёбер!
```
