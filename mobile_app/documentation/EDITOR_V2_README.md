## 🌟 ГЛАВНОЕ: КОРИДОРЫ

**Проблема**: 100 кабинетов = 4,950 рёбер (если соединять все)  
**Решение**: 1 точка типа "Corridor" = 100 рёбер  
**Результат**: 🎉 Уменьшение в 49.5 раза!

```
БЫЛО:                       СТАЛО:
Каб1──Каб2──...──Каб100    Каб1──┐
 ╲  │  ╱                    Каб2──┼──Коридор
  ╲│╱                       Каб3──┤
  (4950 рёбер)              ...   ├────...
                            Каб100┘
                            (100 рёбер)
```

## 📖 КАК ИСПОЛЬЗОВАТЬ

### Быстро (30 секунд)

```
1. ☝️ нажми (режим SELECT)
2. Click на точку → Drag переместить
3. 🔗 нажми (режим LINK)
4. Click первая точка → Click вторая → Готово!
5. 💾 Сохрани
```

### С коридорами (2 минуты)

```
1. ➕ ТОЧКА → "Коридор" (Тип: Corridor) → Добавить
2. ➕ ТОЧКА → "Каб1" (Тип: Room) → Добавить (повторять)
3. ➕ КОРИДОР режим → Click на коридор → Click на каб1
4. Повторить для всех кабинетов
5. 💾 Сохрани
```

### Нужна помощь?

```
Нажми: ℹ️ ПОМОЩЬ
Откроется полная инструкция в интерфейсе
```
