### 3️⃣ Масштабируемые линии маршрутов в зависимости от зума ✅

**Решение**: Добавлена формула масштабирования толщины линий

```python
# Формула: чем ближе zoom, тем тоньше линия
```

**Маршрут рисуется с увеличенной толщиной**:

### 4️⃣ Undo/Redo работает только на одно действие (и не пула) ✅

**Решение**: Переработана система группирования действий

**ДО**: Каждое движение узла на 1 пиксель = одно действие в undo

**ПОСЛЕ**: Действия группируются в "пулы" основанные на времени

```python
# Если действие произошло в течение 0.5 секунд:
if current_time - self.last_action_time > 0.5:
    # Новое действие - добавляем в историю
else:
    # Это продолжение предыдущего действия
    # Обновляем последнее состояние вместо добавления нового
```

**Параметры**:
- `self.action_batch_timeout = 0.5` - группировка действий в течение 0.5 сек
- История ограничена 50 действиями

**Поведение**:
- Передвигаешь узел - все движения в течение 0.5 сек считаются ОДНИМ действием
- Отпускаешь → ждёшь 0.5 сек → начинаешь новое движение = новое действие
- Undo отменяет ВЕСЬ пул движений, а не один пиксель

**Файлы**: 
- `widgets/visual_graph_editor.py` - добавлен callback `on_node_moved_callback`
- `screens/graph_editor_screen.py` - переработана `_save_state()` с группировкой

### 5️⃣ Невидно какие графы соединены в редакторе ✅

**Решение**:
- Рёбра теперь задают цвет на основе связи (серый) 
- При выборе узла рёбра становятся видимыми
- Разные цвета для разных типов:
  - Обычные рёбра: серый (0.5, 0.5, 0.5)
  - Маршрут: зелёный (0.2, 0.8, 0.2)
  - Временное соединение: светло-зелёный (0.2, 0.7, 0.2)

**Визуализация**:
- Выбранные узлы подсвечены жёлтым
- вокруг выбранных узлов рисуется жёлтая граница
- Все соединения выбранного узла видны

**Файлы**: `widgets/visual_graph_editor.py` линии ~337-369, 135
