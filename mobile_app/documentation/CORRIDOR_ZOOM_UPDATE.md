## 🆕 ЧТО ДОБАВЛЕНО

### 1️⃣ СОЗДАНИЕ КОРИДОРОВ (двойной клик)

**ДО**: Нужно было:
1. Нажать "+ Точка"
2. Выбрать тип "Corridor"
3. Click OK

**ТЕПЕРЬ** (намного быстрее):
- **Двойной клик** в режиме ➕ КОРИДОР → ГОТОВО!
- Создаёт новый узел типа Corridor в месте клика
- Он сразу становится активным для соединения

### 2️⃣ КНОПКИ ЗУМИРОВАНИЯ

**Кнопки в верхней панели**:
- 🔍+ = Приблизить (Zoom In)
- 🔍− = Отдалить (Zoom Out)  
- ⟲ 1x = Сброс на 100%
- Показывает текущий процент (100%, 110%, и т.д.)

**Также работает**:
- Колёсико мыши вверх/вниз (как и раньше)
- Клавиши если захочешь добавить

**Диапазон зума**: 0.2x (очень отдалено) до 5.0x (очень приближено)

### Создание коридора за 1 шаг

```
1. Нажми кнопку ➕ КОРИДОР
2. ДВОЙНОЙ КЛИК в пустоту на плане
3. Готово! Коридор создан в этом месте
4. Теперь соедини кабинеты с коридором (режим обычный)
```

### Зумирование

```
СПОСОБ 1: Нажми кнопки 🔍+/🔍−
  • Приближает/отдаляет от центра экрана
  • Показывает процент зума

СПОСОБ 2: Колёсико мыши (если есть)
  • Вверх = приблизить
  • Вниз = отдалить

СПОСОБ 3: Сброс зума
  • Нажми ⟲ 1x
  • Вернёт 100% и центрирует
```
